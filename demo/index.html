The model

Every number on the simulator page comes from model/model.py, which fits both drugs on published concentration data and then checks the result against dosing guidelines it never saw. Run it yourself:

pip install -r model/requirements.txt && python3 model/model.py

The calibration table on the simulator page separates the quantities that set the parameters from the ones held out, because only the second group tests anything.
